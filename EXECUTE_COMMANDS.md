## 💡 TROUBLESHOOTING

**If something goes wrong**, the most common fixes are:

1. **Make sure terminal is in the right folder**
   ```
   You should see the project files listed
   ```

2. **Reinstall dependencies**
   ```powershell
   npm install
   npm run dev
   ```

3. **Clear cache**
   ```powershell
   npm cache clean --force
   npm install
   npm run dev
   ```

4. **Use different port if 3000 is busy**
   ```powershell
   npm run dev -- -p 3001
   ```

5. **Run PowerShell as Administrator**
   - Right-click PowerShell
   - Select "Run as Administrator"
