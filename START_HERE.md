## 🎨 Optional Customizations

### Change Colors
Edit `tailwind.config.ts`:
```typescript
colors: {
  primary: "#your-color",
  secondary: "#your-color",
  accent: "#your-color",
}
```

### Add Project Images
1. Create `public/projects/` folder ✅ (already created)
2. Add your project images (JPG, PNG, WebP)
3. Update paths in `data/content.ts`
